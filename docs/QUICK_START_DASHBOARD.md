# 🚀 Quick Start - Trading Dashboard

## ⚡ 3 Steps to Run

### 1️⃣ Start the Server
```bash
cd trading_dashboard
python app_simple.py
```

### 2️⃣ Open Browser
Go to: **http://localhost:5000**

### 3️⃣ Click "Start Backtesting"
Watch the magic happen! ✨

---

## 📊 What You'll See

### **4 Animated Graphs:**

1. **📈 Price Movement** - Actual vs Predicted prices
2. **💰 Portfolio Performance** - Your money over time
3. **📊 Cumulative Returns** - Profit/loss percentage
4. **🔄 Trading Activity** - BUY/SELL signals + positions

### **Live Stats:**
- 💵 Portfolio Value
- 📈 Total Return %
- 💰 Current Price
- 🔄 Total Trades

## 🐛 Issues?

**Graphs not loading?**
→ Refresh page, check console

**Model not found?**
→ Run `python 8_advanced_model.py` first

**Server won't start?**
→ Install: `pip install flask flask-socketio eventlet`
